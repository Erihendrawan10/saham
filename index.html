📘 Data dasar

🧮 Asumsi per metode

  • DCF: FCF/saham diproyeksi 5 tahun dengan growth FCF, lalu terminal value (Gordon), semuanya didiskon dengan COE. Untuk financial biasanya tidak relevan (bobot default 0%).
  • PBV: BVPS × target PBV. Jika target kosong dipakai PBV wajar = (ROE − g) ÷ (COE − g), dibatasi 0,5–4×.
  • PE: EPS × target PE (disarankan mean PE 5 tahun). DDM: DPS × (1+g) ÷ (COE − g).

📋 Aturan sinyal

  • Fair value = rata-rata berbobot metode DCF / PBV / PE / DDM. Bobot non-financial dan financial dibedakan (atur di Parameter).
  • 🟢 Beli: belum dimiliki dan harga ≤ fair value dikurangi diskon {{ cfg.mos }}%.
  • ✋ Hold: sudah dimiliki dan harga masih di bawah fair value.
  • 🚨 Jual: sudah dimiliki dan harga ≥ fair value (target tercapai).
  • ⏳ Tunggu: belum dimiliki, harga di atas zona beli tetapi masih di bawah fair value. 🔴 Mahal: belum dimiliki dan harga ≥ fair value.
  • Ini alat bantu hitung, bukan rekomendasi investasi. Hasil sangat bergantung pada asumsi yang Anda isi.
